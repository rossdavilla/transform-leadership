# The 4 I's of Transformational Leadership

An interactive page for PSY 170 (I/O Psychology) at UC Merced. Students pick one of the four I's (Idealized Influence, Inspirational Motivation, Intellectual Stimulation, Individualized Consideration) to see what the trait means and an example of a leader who shows it.

**Live:** https://rossdavilla.github.io/transform-leadership/

Images live in `img/`.
